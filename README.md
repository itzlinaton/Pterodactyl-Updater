# Pterodactyl-Updater 🛠️
Basic tool to update Pterodactyl Wings & Panel in one command.

## Supported Systems:
- Ubuntu

## Includes:
- Automatic Panel & Wings update checks every 6 hours.
- Automatic updater script update checks every 6 hours.

(Both are optional)

## Installation Process:
Simply execute:

```sh
curl -sSL https://raw.githubusercontent.com/itzlinaton/Pterodactyl-Updater/main/installer.sh | bash
```

to install the tool. After the installation is complete, you may then execute:
```
ptero-update
```
to initialize a Panel & Wings update whenever required.
